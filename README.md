# 🎮 Who Is Sakib Ibrahim?

### An Interactive RPG-Inspired Personal Portfolio

**Who Is Sakib Ibrahim?** is an interactive personal portfolio designed to present my professional experience, technical skills, education, interests, and career journey through the visual language of a role-playing game.

Rather than creating a traditional portfolio website, I wanted to build an experience that reflects both my professional background and my personality. Visitors navigate through character profiles, inventories, quests, save files, and other RPG-inspired interfaces while learning more about who I am.

🌐 **Live Portfolio:**  
[Explore Who Is Sakib Ibrahim?](https://silverxflows.github.io/WhoIsSakibIbrahim/)

---

## 🕹️ About the Project

**Who Is Sakib Ibrahim?** began as a web development project and evolved into a complete interactive portfolio.

The goal was to combine professional portfolio content with a creative interface inspired by video games and RPG menus. Instead of simply presenting information through traditional sections, the website treats my career, education, skills, interests, and goals as parts of an ongoing character progression.

The project was built with a focus on:

- Responsive web design
- Interactive user experiences
- Semantic HTML
- Reusable CSS
- JavaScript-driven interactions
- Accessibility and keyboard navigation
- Multimedia integration
- Personal branding
- Git version control
- Public web deployment

## ✨ Features

### 🎮 RPG-Inspired Interface

The portfolio uses terminology and design elements inspired by role-playing games, including:

- Character profiles
- Character stats and skill ranks
- Inventory systems
- Quest logs
- Side quests
- Save data
- Loading sequences
- Interactive menus

### 🖱️ Interactive Elements

The website includes several JavaScript and CSS-powered interactions:

- Animated title/loading screen
- Interactive navigation menus
- Keyboard-accessible controls
- Expandable inventory information
- Interactive passion cards
- Video-based content
- Quest details
- Bootstrap accordions
- Bootstrap modal windows
- Responsive layouts

### 📱 Responsive Design

The portfolio is designed to adapt across desktop, tablet, and mobile screen sizes using responsive CSS, Flexbox, CSS Grid, and Bootstrap components.

## 🗺️ Portfolio Sections

### 👤 Character Profile

Introduces my professional background and presents my abilities through an RPG-inspired character sheet, including professional strengths and technical skill rankings.

### 🎒 Inventory

Displays my professional toolkit and current technology loadout.

The Professional Toolkit includes technologies and tools related to:

- BIM coordination
- Autodesk Revit
- AutoCAD
- Navisworks
- HTML
- CSS
- JavaScript
- C#
- SQL
- Visual Studio Code
- Git
- GitHub

The Equipped Gear section provides an interactive look at some of the technology I use in everyday life.

### 🗺️ Journey

An interactive timeline covering major stages of my professional and academic journey, including leadership experience, BIM coordination, higher education, software development, and future career goals.

### 🎯 Current Mission

An RPG-style active quest log highlighting my current objectives in:

- BIM coordination
- Software development
- Higher education
- Technical growth
- Professional development
- Long-term career progression

### ❤️ Passions

An interactive multimedia section showcasing interests outside of work and school, including:

- Technology and PC building
- Gaming
- Anime and manga
- Travel and exploration
- Cooking and food
- Music and soundtracks

### ✈️ Side Quests

A travel-inspired quest log documenting completed adventures, future destinations, and my goal of eventually visiting Japan.

### 💾 Save Data

A collection of important professional, academic, technical, and personal milestones presented as RPG save files.

### 📡 Contact / Credits

The final destination of the portfolio includes professional contact options, development credits, project information, and additional developer notes.
