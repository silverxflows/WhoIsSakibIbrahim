Developer Notes

Who Is Sakib Ibrahim? originally began as a semester-long portfolio project for the CST-120 Web Development course at Grand Canyon University.

Rather than leaving the project behind when the course ended, I decided to continue developing it into a public personal portfolio that could grow alongside my professional and software development journey.

Project Goal

The goal is to create an interactive portfolio that presents my professional background, technical development, projects, interests, accomplishments, and future goals while still showing personality through its visual design.

Technologies Used

  • HTML5 semantic page structure
  • CSS3 styling and reusable variables
  • CSS Flexbox and Grid
  • Responsive media queries
  • JavaScript event handling and DOM manipulation
  • Interactive JavaScript loading sequence
  • Interactive inventory detail system
  • IntersectionObserver video optimization
  • Interactive Passion flip cards
  • jQuery show-and-hide interactions
  • Bootstrap responsive navigation and components
  • HTML5 video and media
  • Google Fonts using Inter and Orbitron

Design Direction

The visual direction is inspired by the stylish, menu-driven presentation found in modern role-playing games. Rather than recreating an existing game's interface, I used that inspiration to develop an original visual system around my own content and portfolio structure.

From Coursework to Public Portfolio

The original course project evolved through multiple development milestones involving multi-page HTML, shared CSS, animations, Flexbox, responsive design, JavaScript, jQuery, Bootstrap, forms, media, and interactive user experiences.

After completing the course, I continued refining the site by improving its content, accessibility, performance, responsive behavior, project organization, and overall presentation for a public audience.

Current Status

This portfolio is an ongoing project. As I gain new skills, complete new projects, progress through my degree, and continue developing professionally, the website will continue evolving with me.
